## Notes (non-blocking)
1. **If the visitor presses Tab while the smooth Back restore is still animating, the page still jumps back down.** The restore animation takes about 0.7 s. In `qa11-earlytab.txt`, a Tab pressed 300 ms or 600 ms after Back (at 1280, default motion) moves focus to "Related work →" or the Research section, with scrollY 1721. A Tab at 100 ms, and any Tab after the restore settles (the QA steps), is fine. This is ordinary browser behaviour, because Tab continues from the focused card. A possible improvement: on a traversal to a URL without a fragment, when the old focus is below the fold, move focus to body as soon as `popstate` fires (or at the start of the restore) instead of waiting until the end. Tool: `f25-a2-qa11-earlytab.mjs`.
2. With smooth motion, the reconcile runs about 0.8–0.9 s after `popstate`, close to the 1 s `SETTLE_CAP_MS`. That's fine, because the frame-poll fallback works independently of the cap: the `scrollend`-suppressed runs pass.
3. The narrow sheet has no scrim, which is a design choice; this was attempt 1's note 2. Playwright's Chromium disables bfcache, so the `pageshow(persisted)` path is still not exercised.
4. The e2e test `expect.poll(offscreenFocus)` retries for up to 5 s, so it would not catch a slower reconcile, as long as it lands under the timeout. My tool samples a fixed window, and it confirms the actual timing.
